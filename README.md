# talking-head-widget

An embeddable 3D talking head for any website: an npm package that puts the head in a corner of the page and plays
clips prepared in the talking-head.dev studio (voice, lip sync, emotions, glances).

Part of the [talking-head.dev](https://github.com/talking-head-dev/talking-head.dev) workspace, where it's a
submodule. Design: the workspace's `docs/embeddable-widget.md`. The work is tracked in Jira as THS-20.
